# Forage extension

WXT + React, Chrome MV3.

## Setup

```sh
cp .env.example .env   # fill in WXT_SUPABASE_URL / WXT_SUPABASE_ANON_KEY
npm install
npm run dev
```

Sign in from the toolbar popup, then select a word on any page and use the
context menu ("Save to Forage") or Alt+Shift+S.

## Tests

```sh
npm test
```
